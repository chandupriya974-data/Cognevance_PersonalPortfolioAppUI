# Chandu Priya - Personal Portfolio App UI Design

## Project Overview
A modern and responsive Personal Portfolio 
App UI designed for a Data Analyst and Power BI Developer.

## Project Objective
The objective of this project is to create a clean, 
professional, and user-friendly portfolio interface
that present skills, projects, education, career goals,
and contact information.

## Design Process
-Research
-Low-Fidelity Wireframes
-High-Fidelity UI Design
-Responsive Design
-Interactive Prototype
-Screenshots and Documentation

## Tools Used
-Figma
-UI/UX Design
-prototyping
-Responsive Design

## Portfolio Screens
-Home
-About Me
-Skills
-Projects
-Contact

## Design Style
The design uses a clean and minimal layout with
a light background, dark typography, blue accent
color, rounded cards, and simple navigation.

## Responsive Design
The portfolio UI was designed with responsive principles
in mind for both mobile and desktop screen sizes.The 
layouts, typography, buttons, navigation, and spacing
were planned to provide a clear and consistent user experience
across different screen sizes.
